# 写作项目起步：给执行 init 的 Agent 看

## 适合什么项目

小说、非虚构、长文这类以文字成品为主的项目。

## 建议的文档地图

| 放什么 | 在哪 | 怎么写 |
| --- | --- | --- |
| 全书大纲 | `大纲.md` | 情节和章节安排，只写现在 |
| 正文 | `正文/<章>.md` | 一章一个文件，见 `正文/AGENTS.md` |
| 人物与世界观 | `设定/` | 只写现在，见 `设定/AGENTS.md` |
| 素材 | `素材/` | 原样保存，见 `素材/AGENTS.md` |
| 写作风格 | `风格.md` | 用词、句式、禁忌 |
| 整体进度 | `STATUS.md` | 写到哪、下一步 |

## 分区规则

### 正文/AGENTS.md

```markdown
# 正文：给写章节的 Agent 看
- 一章一个文件，文件名用章节名。
- 改稿直接改原文件，旧稿在 git 里。
- 待定的情节写进 STATUS 的“等用户决定”，不留在正文里。
```

### 设定/AGENTS.md

```markdown
# 设定：给写人物和世界的 Agent 看
- 一个人物一个文件，文件名叫人物名。
- 只写现在成立的事；设定改了就直接改写。
- 发现和正文冲突，先问用户保留哪一个。
```

### 素材/AGENTS.md

```markdown
# 素材：给整理参考资料的人看
- 收集来的资料原样放这里，文件名写清来源和日期。
- 用过的素材在正文里注明出处。
- 这里的内容可能过时，用之前先核对。
```
