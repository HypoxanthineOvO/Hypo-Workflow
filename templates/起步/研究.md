# 研究项目起步：给执行 init 的 Agent 看

## 适合什么项目

一个人或小组推进研究、要出论文的项目。

## 建议的文档地图

| 放什么 | 在哪 | 怎么写 |
| --- | --- | --- |
| 整体进度 | `STATUS.md` | 只写现在，最多链接到研究线 |
| 用户定下的决定 | `docs/决定.md` | 按主题分组；推翻就改写并注明日期 |
| 一条研究线 | `research/<线>/` | 见 `research/AGENTS.md` |
| 论文与文献 | `papers/` | 见 `papers/AGENTS.md` |
| 原始数据 | `data/` | 到货后不修改，见 `data/AGENTS.md` |
| 会议、转录、合作方原件 | `sources/<来源>/<日期>-<名称>/` | 原样保存，不进 git |

## 分区规则

### research/AGENTS.md

```markdown
# 研究线：给写这个目录的 Agent 看
- 每条线一个目录，README 开头三行：想回答什么、现在的结论、下一步。
- 实验放 experiments/日期-做什么/，README 写问题、条件、结论。
- 结论被推翻：旧实验 README 顶部写“作废：原因，日期”，再改这条线和 STATUS。
- 重跑取代旧结果：旧目录归档，新目录沿用原名，不用 -v2、-final、编号。
```

### papers/AGENTS.md

```markdown
# 论文：给整理文献的 Agent 看
- 一篇一个文件，命名“第一作者-年份-短标题”。
- 每条都写来源（DOI、链接或书目）；查不到就写“来源未知”。
- 只记读过的结论和它支持什么，不整段抄摘要。
```

### data/AGENTS.md

```markdown
# 数据：给用数据的 Agent 看
- 原始数据到货后不改，放 `data/<来源>/<日期>-<名称>/`。
- 处理结果另存，文件名写清从哪批数据来的。
- 删改数据前先问用户。
```

### sources/AGENTS.md

```markdown
# 来源原件：给整理会议和合作材料的 Agent 看
- 原件和转录放 `sources/<来源>/<日期>-<名称>/`。
- 原样保存，不改原文；自己的理解写进 research/ 或 docs/。
- 这个目录不进 git。
```
