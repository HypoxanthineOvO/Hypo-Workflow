# 语义化 Workflow 模板

这些模板是提供给有能力模型的简短写作辅助。复制合适的结构，替换尖括号中的提示，并保持正文适合人类直接阅读。YAML frontmatter 有意保持精简，真正有用的信息写在 Markdown 正文中。

| 模板 | 用途 |
| --- | --- |
| `cycle.md` | 创建一轮有明确边界的项目迭代 |
| `plan.md` | 记录目的、边界、验证和进度位置 |
| `progress.md` | 展示当前状态和下一步 |
| `execution.md` | 记录有意义的执行 checkpoint |
| `discussion-summary.md` | 保存决定和责任证据 |
| `discussion-ledger-local.md` | 在本地追加用户与助手的可见消息 |
| `cycle-summary.md` | 关闭并归档 Cycle，同时保留历史 |
| `memory.md` | 保存一条已确认的长期事实 |
| `experiment.md` | 管理人类可读的 Experiment 与 Attempts |
| `handoff.md` | 只向 Worker 提供它真正需要的细节 |
| `session-focus.yaml` | 在本地声明一个 Session 当前聚焦的 Cycle |
