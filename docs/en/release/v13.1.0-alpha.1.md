# v13.1.0-alpha.1 Release Notes

[中文](../../release/v13.1.0-alpha.1.md) | English

v13.1.0-alpha.1 was released on 2026-05-30. This 13.1 alpha packages the C18 instruction-quality and integration-sync cycle: enhanced `/hw:audit`, first-class `/hw:quality`, first-class `/hw:optimize`, and a target-repository integration sync release gate for `Codex-VSP` and `VSP-Open-Code`. It is an alpha release and does not claim stable status.

## Highlights

- **Audit engineering upgrade**: `/hw:audit` is now intake-first, uses Experience, Engineering, and Risk lenses, and ends with Critical blocking plus an Action Queue.
- **First-class Quality command**: `/hw:quality` produces scorecards, baseline/compare output, review notes, and a prioritized Action Queue.
- **First-class Optimize command**: `/hw:optimize` coordinates Audit+Quality -> Implement/Test -> Audit+Quality with backup, correctness, budget, and validation gates.
- **Integration sync release gate**: integration sync is documented as a source-side development/release workflow, not a user command.
- **Target repository adaptation**: C18 was adapted into `~/Codex-VSP` and `~/VSP-Open-Code`, with target-side records and focused validation.
- **Feedback import path**: ordinary conversation and Journal records can be classified as audit, quality, optimize, or integration_sync candidates before user-confirmed promotion.

## Fixes

- Fixed command maps, OpenCode/Cursor/third-party adapters, and docs so `quality` and `optimize` are exposed as Workflow commands while integration sync remains outside the user command namespace.
- Clarified the source/target boundary: the source repository owns command semantics, Skills/specs, generators, and release gates; target repositories adapt according to their current local state.
- Fixed OpenCode target reminder wording so it does not expose `/hw:integration-sync` as a pseudo-command.
- Refreshed OpenCode adapter, compact derived artifacts, and generated docs so release preflight reports `derived=fresh`.

## Documentation And Sync

- README / README.en now point to v13.1.0-alpha.1 alpha release notes and describe the C18 Audit/Quality/Optimize and integration sync scope.
- Docs governance now maps the active release note to v13.1.0-alpha.1.
- Version sources are synced to 13.1.0-alpha.1: `.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json`, `.codex-plugin/plugin.json`, `.opencode/hypo-workflow.json`, `.opencode/plugins/hypo-workflow.ts`, `.opencode/package.json`, `cli/package.json`, `core/package.json`, default config version, and generator `HW_VERSION`.
- Added C18 target adaptation plans, integration matrix, test evidence, implementation evidence, audit report, and M6 completion report.

- This release prepares the release commit, tag, and push path, but does not perform npm publishing.
