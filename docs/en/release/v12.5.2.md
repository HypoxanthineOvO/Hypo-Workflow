# v12.7.0 Release Notes

[中文](../../release/v12.7.0.md) | English

v12.7.0 was released on 2026-05-14. This patch fixes OpenCode bash auto-approval by removing unsupported `bypass` permission values and moving safe local command approval into the Hypo-Workflow plugin policy.

## Fixes

- Generated OpenCode `opencode.json` now keeps `*: ask`, `edit: ask`, `bash: ask`, and `question: allow`.
- Added `execution.bash.mode=allow_local` so Hypo-Workflow policy can auto-allow local test, lint, build, format, sync, docs repair, and local search commands.
- `git push`, PR/MR remote writes, network commands, remote clone, publish, destructive commands, system installs, and release publish still Ask.
- Added the structured `opencode-bash-auto-policy` rule to prevent future regeneration of `permission: bypass`.

## Tests

- OpenCode bash policy, config/profile, adapter artifact, and generated plugin tests passed.
- `opencode debug config` passed, confirming OpenCode schema compatibility.
