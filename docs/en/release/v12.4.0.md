# v12.4.0 Release Notes

[中文](../../release/v12.4.0.md) | English

v12.4.0 was released on 2026-05-11. It closes the C11 workflow-experience cycle: Chinese-first Skills and references, stronger planning interviews and example abstraction, Subagent injection discipline, durable automation authorization, and final local-distribution regression fixes.

## Highlights

- Skills and key references now use Chinese body structure while preserving command names, config keys, file names, and platform terms in English.
- `/hw:plan` flows strengthen P0/P1 discovery by abstracting user examples into generalized requirements before milestone decomposition.
- Subagent templates now separate the Layer 1 host envelope from Layer 2 task checks so platform rules and task-specific validation stay distinct.
- Automation authorization, Codex Subagent scope, worker separation, and analysis boundaries are recorded across config, reports, and validation evidence.
- Scenario regressions `s19-help-list` and `s56-agents-ask-todo-plan-discipline` now check the localized canonical anchors instead of stale English headings.
