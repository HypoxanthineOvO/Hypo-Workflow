# v12.4.0 Release Notes

[中文](../../release/v12.4.0.md) | English

v12.4.0 was released on 2026-05-11. It adds a completion-oriented acceptance alias and refreshes the platform adapters.

## Changes

- Added `/hw:achieve` as an alias for `/hw:accept`.
- Added the OpenCode native command `/hw-achieve`, still routed to `skills/accept/SKILL.md`.
- `/hw:achieve` and `/hw:accept` share the same worker-separation gate, Cycle acceptance lifecycle, log entry, and derived refresh behavior. There is no second acceptance path.
- Version metadata is now `12.4.0`; README files, user guides, command references, and Skill inventory now reflect 40 user-facing commands.

## Validation

- Targeted tests cover command mapping, accept/achieve routing, Skill inventory, docs governance, README updates, and platform adapters.
- Platform adapters were regenerated with `hypo-workflow sync --platform opencode` and `hypo-workflow sync --platform claude-code`.
