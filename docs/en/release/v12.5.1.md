# v12.5.1 Release Notes

[中文](../../release/v12.5.1.md) | English

v12.5.1 was released on 2026-05-12. This patch restores Claude Code `hw` plugin slash-command exposure and normalizes release notes into the standard grouped structure.

## Features

- The Claude Code plugin now generates plugin-root `commands/*.md` slash command files so `/hw:*` entries are discoverable and autocompletable in Claude Code.
- Added 40 Claude Code command mappings, including `/hw:patch`, `/hw:resume`, `/hw:plan:deep`, and `/hw:plan:discover`; command files load the existing `skills/*/SKILL.md` authority instead of creating a second implementation.
- Added the `/hw:plan:deep` deep discussion/planning entrypoint with discussion packages for ask, research, architecture maps, readiness, and Feature Queue handoff.
- Added the project structured rule `claude-hw-command-namespace` at `error` severity to enforce the `hw` namespace and keep Claude native `/resume` separate from Hypo `/hw:resume`.

## Fixes

- Fixed the local Claude Code behavior where only the aggregate `/hypo-workflow` entry appeared and `/hw:` had no completions.
- Fixed stale documentation and setup skill wording that promoted `/hypo-workflow:<command>` as the primary Claude Code path.
- Preserved `/hw:resume` without registering a bare `/resume`, avoiding another collision with Claude Code native Resume.
- Normalized the Chinese v12.3.0, v12.4.0, and v12.5.0 release notes into `Features` / `Fixes` / `Documentation` / `Tests` sections.

## Documentation

- Updated the Claude Code platform guide, platform capability matrix, commands spec, and setup skill to document the plugin-root `commands/` plus `hw` namespace boundary.
- GitHub Release notes now use the standard Chinese grouped structure; `docs/en/**` remains English.
