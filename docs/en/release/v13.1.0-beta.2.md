# v13.1.0-beta.2 Release Notes

[中文](../../release/v13.1.0-beta.2.md) | English

v13.1.0-beta.2 source release candidate was prepared on 2026-06-30. This 13.1 beta packages the C19 Workflow core and Plan mode optimization plus the C20 consultation-first action boundary. It remains a beta release, does not perform npm publishing, and does not claim that C20 has been deployed into `Codex-VSP` or `VSP-Open-Code`; those targets receive target-local Cycle handoff material only.

## Highlights

- **Named Plan phases**: the user-facing Plan flow now uses `Discover -> Technical Stack -> Architecture -> Decompose -> Generate`, with new `/hw:plan:technical-stack` and `/hw:plan:architecture` entries.
- **Visible in-phase gates**: major confirmations must show phase summaries, decision tables, open questions, and diagrams before Question Tool / Ask confirmation. `/hw:plan:confirm` is no longer a user-facing entry.
- **Consultation-first action boundary**: discussion, background, idea, complaint, question, and solution-discussion inputs are non-editing signals and must first produce a Mini-contract in the order `我的理解` -> `问题原因` -> `推荐方案`.
- **Direct execution preserved**: clear imperatives with concrete targets may still execute directly; post-plan replies such as `可以`, `确认`, `OK`, `go ahead`, and `apply it` authorize only the displayed scope.
- **Target handoff**: C20 adds target-local Cycle input for `Codex-VSP` and `VSP-Open-Code`, separating source direct sync from target-owned prompt and runtime optimization.
