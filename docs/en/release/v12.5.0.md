# v12.5.0 Release Notes

[中文](../../release/v12.5.0.md) | English

v12.5.0 was released on 2026-05-12. It cleanly ports the useful audit governance work from GitHub PR #7 into the current mainline while avoiding a direct merge of `.pipeline/**` runtime state, generated docs, and release artifacts.

## Highlights

- Ported audit governance hardening from PR #7: `audit` may intervene before milestone completion, and rejection scope now covers `milestone`, `feature`, and `cycle`.
- Added audit memory runtime helpers for cycle-level audit memory, milestone-level audit delta, scoped audit summaries, and the rule that raw free-form conversation is not authority.
- Added rejection rework and blocked runtime helpers: `implement` may only propose blocked, `audit` must approve blocked, and rework preserves the original prompt plus incremental scope.
- Hardened worker separation: acceptance now checks persisted `prompt_scope`, `changed_files`, and worker scope evidence to block cross-role ownership, out-of-scope writes, and audit file mutations.
- Added `/hw:pr` path policy for create/review flows: `.pipeline/**` runtime files are blocked by default, while `.pipeline/pr/**` local evidence archives remain allowed.

## Not Merged Directly

- The original PR #7 branch was not merged wholesale because it mixed `.pipeline/**` runtime state, prompts, release notes, README, and CHANGELOG changes into the implementation branch.
- The `/hw:achieve` public command alias was not added; that command remains a separate product decision.
- Docs-only Codex snapshot guidance and plan prompt architecture assertions were left for a separate documentation pass.
