# v12.8.0 Release Notes

[中文](../../release/v12.8.0.md) | English

v12.8.0 was released on 2026-05-16. This release closes the C15 Workflow interaction improvements and repairs the pre-release regression suite.

## Highlights

- **P2 technical-route gate**: P2 no longer delivers only a Milestone target list. Before P3, every Milestone must expose its technical plan, route, research basis, risks, uncertainties, and review questions.
- **Completion report contract**: Milestone, Cycle, Debug, Audit, and Patch completions must cover what changed, technical reasoning, files/modules touched, test design, validation results, expected outcome, encountered issues, and risks/follow-up.
- **Analysis restored**: `/hw:analysis` is a first-class entrypoint again, with its own Skill, command mappings, status surfaces, ledger path, and compact summary.
- **Shared asset path contract**: the Cycle child skill no longer treats shared `assets/state-init.yaml` as a child-local path, and regression checks now protect that contract.

## Fixes

- Repaired the full pre-release regression from 55/68 to 68/68.
- Updated v8/v9 scenario smokes for current Chinese/bilingual Skill wording, Guide/Showcase/PROGRESS contracts, and fixed-string matching.
- Updated core contract tests for the current OpenCode `allow` policy, DeepSeek model matrix, rich TUI plugin surface, Chinese Subagent separation wording, and Chinese workflow commit wording.
- Added `completed_with_transport_error` to lifecycle log status validation to match real worker transport-error completion records.
- Added the fake `solid-js` `For` export needed by OpenCode panel tests.
