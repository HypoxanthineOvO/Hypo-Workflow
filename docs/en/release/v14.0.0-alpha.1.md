# v14.0.0-alpha.1 Release Notes

[中文](../../release/v14.0.0-alpha.1.md)

v14.0.0-alpha.1 is the first 14.0 prerelease of the manifest-based Hypo-Workflow architecture. It supersedes `v13.1.0-beta.3`: that release remains technically valid, but its version understated the breaking Runtime, Host Contract, command-surface, and host-authority changes.

## Why Alpha

- The core path is usable and fully validated, while Runtime schemas, installation protocols, and platform adapters may still change.
- Codex is the primary path; OpenCode, Claude Code, experiment management, and Stash/Pop still have follow-up work.
- The project does not claim Beta-level contract stability until real-project validation and public-interface freeze.

## Fixes and Version Correction

- Correct the versioning and stability signal from `v13.1.0-beta.3` without moving or deleting the historical tag.

## Core Changes

- Hypo-Workflow exclusively owns lifecycle semantics, Runtime, Records, Receipts, the Recovery Journal, and workspace writes.
- The public surface is exactly nine commands: `guide`, `init`, `goal`, `plan`, `cycle`, `maintain`, `resume`, `accept`, and `reject`.
- Host Contract v1 exposes a recursively validated read-only Host Status and fails closed for damaged, invalidated, legacy, unknown, or sensitive data.
- Reproducible Codex plugin and portable ZIP artifacts bind the source commit and SHA-256 checksums.
- Destructive cleanup is bound to an exact manifest, a single-use Receipt, and an execution report.

## Tests

- Hypo maintained Core `486/486`, scenarios `8/8`, and Bootstrap `67/67`.
- Codex Host/routing/TUI/palette `5/5 + 4/4 + 8/8 + 1/1`.
- OpenCode Host/real ZIP `7/7` and related broad tests `26/26`.
- The real portable ZIP passed the complete temporary active-root installation chain.

## Next Stage

The project will move to `v14.0.0-beta.1` after the public contract is substantially frozen, Codex is stable in real project use, and the primary OpenCode adaptation is complete.
