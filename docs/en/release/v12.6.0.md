# v12.7.0 Release Notes

[中文](../../release/v12.7.0.md) | English

v12.7.0 was released on 2026-05-14. This version adds OpenCode command registration and TUI panel enhancements.

## Key Changes

### OpenCode Command Registration

- Added `command` field to `opencode.json` to register all `/hw-*` commands
- Fixed parameter errors for `/hw-start`, `/hw-resume`, and other commands
- Command templates automatically load the corresponding Hypo-Workflow skill files
- Distributed to all local repositories (26 repos)

### TUI Panel Enhancements

- Added debounced refresh (150ms) to prevent frequent re-renders
- Added Cycle switch loading animation
- Added smart collapse: sections with >4 items or >200 characters auto-collapse
- Added ASCII progress bar `[████░░] 80%`
- Added section title color coding (Current=cyan, Models=magenta, Milestones=green, Metrics=blue, Recent=yellow, Warnings=red)
- Added status keyword coloring (active=green, done=gray, error=red, pending=yellow, paused=blue)
- Added ID coloring (C13, M0, F001 etc. in cyan)
- Added click-to-toggle section collapse/expand

### Permission Configuration

- `opencode.json` permissions set to `allow`
- All bash execution confirmations disabled (`confirm_external/destructive/system_install: false`)
