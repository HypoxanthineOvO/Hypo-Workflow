# v13.0.0-alpha.1 Release Notes

[中文](../../release/v13.0.0-alpha.1.md) | English

v13.0.0-alpha.1 was released on 2026-05-21. This 13.0 alpha packages the C16 root project management mode work plus the C17 audit remediation and architecture debt reduction cycle. It delivers global maintenance, Notion legacy reconciliation, Knowledge projection, root `npm test`, configuration-driven paths, workspace clean split, unified YAML parsing, JSONL ledger authority, and an explicit public export surface. It is an alpha release and does not claim stable status.

## Highlights

- **Root project management mode**: adds Global Workspace authority, Artifact Catalog, Storage Sync Template, Maintenance Queue/Ledger/Run, Global Consolidation, Global Knowledge/Rules/Secret Reference projection, and the final Notion apply gate.
- **Audit remediation closure**: closes the C17 audit source file's 3 Critical findings, 5 Warning findings, and 5 Info findings. `ARCH-05` broader module-boundary work and `QUAL-06` Deep Plan split remain follow-up candidates and do not block alpha.1.
- **First-class maintenance commands**: adds `/hw:maintain status|scan|plan|queue|run|apply|verify|log`, so long-lived maintenance objects, partitioned maintenance, system-initiated maintenance, and user-directed maintenance no longer hide inside `/hw:sync` or ordinary Cycles.
- **Portable runtime and root tests**: adds repository-root `npm test`, removes `/home/heyx/...` assumptions from `core/src` and `scripts`, and keeps user-level config migration behind explicit commands.
- **Clearer architecture boundaries**: removes the old workspace public entry, splits it into `workspace-authority`, `project-linkage`, `project-stop-events`, `codex-capture`, and `notification-sender`, and replaces the root broad barrel with explicit re-exports.
- **Data authority cleanup**: unifies config/knowledge YAML through `js-yaml`; high-frequency ledger writes now append to JSONL, while compact YAML is metadata summary only.
- **Daily 04:00 global consolidation**: adds `hypo-workflow maintain-scheduler --dry-run` and `scripts/maintenance-scheduler.sh`, producing safe-local global consolidation evidence and a maintenance ledger event without Notion apply, publication, service restart, or pipeline execution.
- **Project-scoped Global Knowledge loading**: adds project Global Knowledge projections and compact rendering. SessionStart reads only `~/.hypo-workflow/knowledge/projections/projects/<project-id>.compact.md` plus the YAML index, not raw global records or candidates by default.

## Fixes

- Revised the post-rejection C16 Notion sync path from creating an extra child sync page to reconciling the existing `Hypo-Workflow` page and its existing child pages through scan, manifest, merge draft, safe apply payload, backups, and read-back verification.
- Hardened the final Notion apply gate with dry-run hash binding, reviewed apply plan id/hash binding, exact confirmation text, explicit target binding, approved operation subsets, re-read verification, and sanitized ledger/evidence output.
- Fixed the SessionStart hook stdout contract so it emits parseable JSON only, with the Global Knowledge compact projection injected through additional context.
- Cleaned Notion legacy reconciliation residue, including flat index blocks, `归位 —` title prefixes, quote residue, pseudo-Markdown code blocks, `top[n]` markers, and bare Markdown heading residue.
- Fixed the missing repository-root test entry; `npm test` now runs the complete Node test suite from the repository root.
- Fixed user-specific path assumptions and Hypo-Claw/Hypo-Writer/project seed coupling by moving paths to layered config or `$HOME`-derived defaults.
- Fixed split YAML parser behavior by routing config and knowledge YAML through shared `js-yaml` helpers.
- Fixed the workspace God Module, old workspace compatibility surface, notification `new String()` payload hack, and root broad barrel export.
- Fixed long-term YAML ledger authority rewrites in project events, notifications, maintenance, daily summary, and global consolidation by moving the authority to JSONL append.

## Alpha Boundaries
