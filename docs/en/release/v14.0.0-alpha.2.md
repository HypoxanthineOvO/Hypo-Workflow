# v14.0.0-alpha.2 Release Notes

[中文](../../release/v14.0.0-alpha.2.md)

v14.0.0-alpha.2 adds experiment management to the published Codex surface and introduces semantic Worker Routing as a decision separate from Worker topology. The release remains Alpha: the core protocol and maintained regression boundary are closed, while real-project experiment pilots, concrete VSP-Codex model mapping, and other platform adapters remain future work.

## Experiment Management

- `/hw:experiment` is a durable nonlinear lane alongside Goal, Cycle, and Maintain. Workflow records and validates experiment facts; the host Agent still executes commands, monitors processes, transfers files, retries work, and analyzes results.
- Project knowledge can capture purpose, paper and documentation references, metric meanings, dataset units, major modules, optimization locations, and concept-to-code mappings. Code changes trigger stale-knowledge checks.
- Reproducible context binds Git code snapshots, the `uv` environment and lock digest, machine/GPU/driver/CUDA facts, external data locations, commands, parameters, resource limits, and readable output directories. Conda is not introduced by default.
- Logical Experiments are separate from Attempts. An explicit rerun creates another Attempt, while a different dataset or scene has a different experiment identity. Incorrect or obsolete Attempts go to trash, remain restorable, and require fresh authorization for permanent deletion.
- Scan design supports one-axis and cross-axis sweeps, screening-to-full-data expansion, fixed parameters, feasibility limits, and resource-limited outcomes such as OOM.
- Long-running work supports foreground or isolated tmux supervision, polling, interruption evidence, and real checkpoint recovery. Without a checkpoint, the record explicitly says that the run restarts from scratch.
- Operational completion is not scientific success. Reviews compare default and contextual baselines, paper expectations, neighboring runs, metric semantics, and resource limits. Suspicious conclusions require user confirmation.
- Immutable Experiment events support Git union. A materialized status projection directly summarizes baselines, environments, datasets, scan purposes, outcomes, exceptions, retention risks, and next actions without rescanning result trees.

## Semantic Worker Routing

- Topology first decides whether independent test, implement, audit, or other identities are needed. Routing only emits a capability requirement for an already selected Worker and never changes roles, evidence, acceptance, or user authority.
- Before Worker start, the host AI shows a Task Assessment containing `complexity`, `uncertainty`, `oracle_strength`, `blast_radius`, `reversibility`, `risk_flags`, and a concise conclusion.
- Core deterministically applies `escalation > critical > explore > standard > mechanical` and emits a reason code. It does not call another model or select a provider, concrete model, credential, or reasoning effort.
- `off` omits the hint, `advisory` records a fallback when the host lacks support, and `required` blocks a Worker whose host cannot accept the semantic handoff.
- Escalation requires two distinct failed execution routes. Same-route retries, user cancellation, Worker startup failure, and network failure do not accumulate.
- Runtime, Continuation, Worker Journal events, and the Recovery Capsule preserve the assessment, class, reasons, failure count, and policy version. Resume reuses the persisted decision instead of reclassifying.

## Hook Fix

- Codex turn Hooks now accept valid host inputs that omit `turn_id` or `tool_use_id`, stopping repeated compatibility failures.
- Hooks remain concurrent guardrails rather than lifecycle authority, authorization authority, or an experiment runner. Hook trust policy is unchanged.

## Distribution And Documentation

- Host Contract v1 and both ZIP artifacts move from nine to ten public Skills and now include `/hw:experiment` with its agent metadata.
- README, the user guides, command and configuration references, Codex platform guides, CHANGELOG, and plugin metadata document the complete release behavior and boundaries.
- Workflow emits only semantic routing classes. Luna/Sol, providers, reasoning effort, credentials, and cost mapping remain host-owned concerns such as VSP-Codex.

## Known Boundaries

- Real NeRF, AceSim, GPU, paper reproduction, GitLab remote, SSH/SCP, large-trace, and multi-week behavior still require a real-project Pilot.
- Scientific reasonableness is a weak oracle. AI may flag a suspicious result, but the final conclusion requires user confirmation.
- The release records machine and environment facts for individual experiments; it does not yet manage whole-computer proxies, ports, services, tools, Key locations, SSH inventory, symlinks, or binaries.
- OpenCode, Claude Code, and custom Codex forks remain outside the current support surface. Concrete VSP-Codex model routing is not implemented in this repository.
