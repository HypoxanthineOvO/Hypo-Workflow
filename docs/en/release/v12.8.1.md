# v12.8.1 Release Notes

[中文](../../release/v12.8.1.md) | English

v12.8.1 was released on 2026-05-17. This patch release integrates PR #8, focused on Cursor adapter flat Skills/commands sync and the self-contained `/hw-setup` fix.

## Highlights

- **Cursor flat Skills/commands**: `hypo-workflow sync --platform cursor --project .` now writes one `.cursor/skills/hw-*.md` file and one `.cursor/commands/hw-*.md` file for each `/hw-*` entry.
- **Compact resource bundle**: `.cursor/hypo-workflow/` mirrors the compact shared references, assets, adapters, and scripts needed by Cursor execution.
- **Clear model boundary**: the Cursor adapter does not write or recommend concrete model/provider defaults. Model selection remains owned by the active Cursor UI/session.
- **PR #8 archive**: this release keeps the local `.pipeline/pr/PR-20260517-001/` review evidence for request changes, fix verification, approval, and merge.

## Fixes

- Fixed generated Cursor `/hw-setup` content that previously pointed to an unmirrored `references/config-spec.md`.
- `/hw-setup` is now self-contained; if source-repository paths are absent from a target project, they are treated as external/non-local and the embedded authority plus mirrored resources provide the fallback.
- Added regression coverage for generated Cursor Skill references so missing local paths must be explicitly external/non-local and include fallback behavior.
- Added the `pr` lifecycle log family and PR review/merge statuses to the validator and `references/log-spec.md`, so `.pipeline/pr/` archive events pass full regression validation.

## Documentation And Sync

- README / README.en now point to v12.8.1 release notes.
- Cursor Guide, Platforms Reference, Generated Artifacts Reference, and Skill spec now describe the flat Skills/commands structure.
- Version sources are synced to 12.8.1: `.claude-plugin/plugin.json`, `.codex-plugin/plugin.json`, `.opencode/package.json`, `cli/package.json`, `core/package.json`, default config version, and generator `HW_VERSION`.
