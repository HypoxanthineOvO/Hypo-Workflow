# v14.0.0-alpha.5 Release Notes

[中文](../../release/v14.0.0-alpha.5.md)

v14.0.0-alpha.5 fixes Codex Hook packaging and terminal compaction regressions in v14.0.0-alpha.4. Concurrent Work Placement behavior is unchanged.

## Fixes

- Codex plugin and portable bundles include `js-yaml` and its transitive `argparse` dependency. Versions are checked against `package-lock.json`, and no post-install network access or `npm install` is required.
- `PreCompact` and `PostCompact` return successfully when the selected Delivery is already `accepted` or `rejected`; a terminal object is not required to retain a Context Capsule.
- Upgrade guidance preserves old plugin caches while active Sessions still reference their pinned `PLUGIN_ROOT` paths.

## Verification

- A focused semantic regression covers terminal Delivery compaction without a Capsule.
- Release contract checks require both runtime dependencies and import the serialization module directly from a clean extracted bundle.
- Installation smoke tests execute real `PreCompact` and `Stop` Hook processes instead of checking registration alone.

## Upgrade Requirement

- `codex plugin add` automatically prunes older caches for the same plugin ID. Snapshot the active version first and restore it at the exact path during the same installation flow.
- Validate the new version from a brand-new Session; resuming an old Session keeps its previous `PLUGIN_ROOT`.
- Remove an old cache only after all Sessions pinned to it have ended.
