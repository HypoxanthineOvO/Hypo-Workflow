# v13.1.0-beta.1 Release Notes

[中文](../../release/v13.1.0-beta.1.md) | English

v13.1.0-beta.1 was released on 2026-05-31. This 13.1 beta builds on the v13.1.0-alpha.1 Audit / Quality / Optimize command system and closes the log schema, Quality log integration, and notification payload maintainability issues found by the first `/hw:quality` scorecard. It remains a beta release and does not perform npm publishing.

## Highlights

- **Quality review closure**: added `.pipeline/quality/quality-001.md`, `actions.yaml`, and `state.yaml` with the current project scorecard, gate result, and action queue.
- **C18 beta closure**: this release inherits the v13.1.0-alpha.1 integration sync / Codex-VSP / VSP-Open-Code adaptation context and focuses on closing the source-side Quality and log runtime boundaries.
- **Log schema closure**: lifecycle log now supports the `quality` family and accepts release preparation / partial publication statuses: `prepared` and `partially_published`.
- **Release family fix**: fixed `release` events being misclassified as `recovery` because `release` contains the substring `lease`.
- **Notification payload cleanup**: `notificationStdinPayload` no longer returns a `new String()` wrapper. It now returns an explicit plain object while preserving `includes()`, `String(stdin)`, and `toJSON()` behavior.

## Fixes

- Fixed `.pipeline/log.yaml` v13.1.0-alpha.1 release records failing `validateLifecycleLog`.
- Fixed the integration gap where `/hw:quality` specified `type: quality` persistence but runtime log families did not include Quality.
- Added regression coverage for release and quality log records so future release events are not misclassified.
- Added Hypo-Claw notification stdin coverage to ensure the payload is no longer a `String` wrapper and still serializes the original message.

## Documentation And Sync

- README / README.en now point to v13.1.0-beta.1 beta release notes.
- Docs governance now maps the active release note to v13.1.0-beta.1.
- Version sources are synced to 13.1.0-beta.1: `.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json`, `.codex-plugin/plugin.json`, `.opencode/hypo-workflow.json`, `.opencode/plugins/hypo-workflow.ts`, `.opencode/package.json`, `cli/package.json`, `core/package.json`, default config version, and generator `HW_VERSION`.
- `references/log-spec.md` documents the `quality` type and the release statuses already used before this beta.
