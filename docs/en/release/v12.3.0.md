# v12.3.0 Release Notes

[中文](../../release/v12.3.0.md) | English

v12.3.0 was released on 2026-05-09. It cleanly integrates the worker-separation feature work from GitHub PR #5 into the current mainline and documents the end-of-run compact refresh and OpenCode status boundaries.

## Highlights

- `/hw:accept` now blocks missing or colliding `test` / `implement` / `audit` worker evidence, failed or `close_failed` lifecycle records, missing Codex `/hw:start` + `/hw:resume` authorization scope, and runtime-only subtask observations being used as acceptance evidence.
- Successful `/hw:start` and `/hw:resume` runs refresh compact targets only when `compact.auto=true` and `compact.end_of_run=true`; the default `compact.refresh_policy=dirty_only` updates only dirty compact targets.
- OpenCode status may display active subagent/model data, but those `subtask` parts are runtime-only and cannot satisfy `/hw:accept` worker evidence.
- GitHub PR #5 was integrated locally and cleanly: the `feat: harden worker separation acceptance` feature content was kept, while the stale PR #3 `13.0.0` version bump and old `.pipeline/` runtime artifacts were dropped.
