# v14.0.0-alpha.5 发布说明

[English](../en/release/v14.0.0-alpha.5.md)

v14.0.0-alpha.5 修复 v14.0.0-alpha.4 的 Codex Hook 发布与终态压缩问题。并发 Work Placement 功能不变，本版本只收紧安装完整性和 Hook 生命周期边界。

## 修复

- Codex plugin 与 portable bundle 显式包含 `js-yaml` 及其传递依赖 `argparse`。依赖版本与 `package-lock.json` 校验一致，解压后无需联网或执行 `npm install`。
- `PreCompact` 和 `PostCompact` 在选中的 Delivery 已经 `accepted` 或 `rejected` 时直接成功返回；终态对象没有 Context Capsule 属于正常状态。
- 保留 active Session 引用的旧插件 cache，避免在线升级删除旧 `PLUGIN_ROOT` 后产生 `MODULE_NOT_FOUND`。

## 验证

- 保留终态 Delivery 无 Capsule 的 Pre/PostCompact 语义回归。
- 发布契约检查 ZIP 中的两项运行时依赖，并从干净解压目录直接加载 serialization 模块。
- 安装验证必须实际执行 `PreCompact` 与 `Stop`，不能只检查 `plugin list`。

## 升级要求

- `codex plugin add` 会自动清理同一插件 ID 的旧 cache。执行前必须快照活动版本，并在同一安装流程内把它恢复到原绝对路径。
- 安装新版本后启动全新 Session 验证；resume 原 Session 仍使用旧 `PLUGIN_ROOT`。
- 只有确认旧 Session 全部结束后，才能清理旧 cache。
