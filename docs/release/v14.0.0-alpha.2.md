# v14.0.0-alpha.2 发布说明

[English](../en/release/v14.0.0-alpha.2.md)

v14.0.0-alpha.2 将实验管理正式加入 Hypo-Workflow 的 Codex 发布面，并新增与 Worker topology 独立的 semantic Worker Routing。该版本继续使用 Alpha：核心协议和维护回归已经闭合，但真实实验项目 Pilot、VSP-Codex 具体模型映射和其他平台适配仍未完成。

## Experiment 管理

- `/hw:experiment` 是 Goal、Cycle、Maintain 之外的长期非线性通道。Workflow 记录和验证实验事实，宿主 Agent 仍负责执行命令、监控进程、SCP、重试和结果分析。
- 项目知识可记录实验目的、论文与文档引用、指标含义、数据集单位、主要模块、优化点和 concept-to-code 映射；代码变化会触发 stale knowledge 检查。
- 可复现上下文绑定 Git 代码快照、`uv` 环境和 lock digest、机器/GPU/驱动/CUDA、外部数据位置、命令、参数、资源限制与可读输出目录。默认不引入 Conda。
- 逻辑 Experiment 与 Attempt 分离：明确重跑生成新的 Attempt；数据集或 scene 不同则是不同实验身份。错误或过期 Attempt 进入 trash，可恢复，永久删除仍需新的明确授权。
- 参数设计支持单轴扫描、交叉扫描、screening 后扩展全量数据、固定参数、可行性边界和 OOM 等资源受限结果。
- 长任务支持前台或隔离 tmux 监督、轮询、中断证据和真实 checkpoint 恢复；没有 checkpoint 时记录从头重跑。
- 程序结束不等于科学成功。结果会对照 default/contextual baseline、论文预期、邻近运行、指标语义和资源边界；可疑结论进入用户确认，不会被 AI 静默接受或否定。
- immutable Experiment events 支持 Git union；materialized status projection 直接回答 baseline、环境、数据集、扫描目的、outcome、异常、保留风险和下一步，不需要重新扫描结果树。

## Semantic Worker Routing

- Topology 先决定是否需要 test、implement、audit 等独立身份；Routing 只为已确定的 Worker 输出能力需求标签，不改变角色、证据、验收或用户授权。
- 宿主 AI 在 Worker 启动前显示 Task Assessment：`complexity`、`uncertainty`、`oracle_strength`、`blast_radius`、`reversibility`、`risk_flags` 和简短结论。
- Core 按确定性优先级输出 `escalation > critical > explore > standard > mechanical` 及 reason code，不调用另一个模型，也不选择 Provider、具体模型、凭据或 reasoning effort。
- `off` 不传路由；`advisory` 在宿主不支持时记录 fallback；`required` 阻止不支持 semantic handoff 的 Worker 启动。
- 两条不同执行路线失败才触发 `escalation`；同一路线重试、用户取消、Worker 启动失败和网络错误不累计。
- Runtime、Continuation、Worker Journal 和 Recovery Capsule 保存评估、档位、原因、失败计数与 policy version；Resume 复用原决定，不重新猜测。

## Hook 修复

- Codex turn Hooks 兼容缺少 `turn_id` 或 `tool_use_id` 的合法宿主输入，停止重复报错。
- Hook 仍是并发 guardrail，不是 lifecycle、授权或实验 runner；本版本没有放宽 Hook 信任策略。

## 发布与文档

- Host Contract v1 和两个 ZIP 从九个公开 Skill 更新为十个，正式包含 `/hw:experiment` 及其 agent metadata。
- README、用户指南、命令参考、配置参考、Codex 平台说明、CHANGELOG 与插件描述同步本版本完整能力和边界。
- Workflow 只发布 semantic routing class；Luna/Sol、Provider、reasoning effort、凭据和成本映射继续由 VSP-Codex 等宿主实现。

## 已知边界

- 真实 NeRF、AceSim、GPU、论文复现、GitLab remote、SSH/SCP、大 trace 和多周运行尚需真实项目 Pilot。
- 科学合理性是 weak oracle；AI 可以标出可疑结果，但最终结论需要用户确认。
- 当前只保存单次实验所用机器和环境快照，不包含整台电脑的代理、端口、服务、工具、Key 位置、SSH、软链接和二进制全局资产管理。
- OpenCode、Claude Code 与自定义 Codex fork 仍不属于当前支持面；VSP-Codex 的具体模型路由不在本仓库实现。
