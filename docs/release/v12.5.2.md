# v12.5.2 发布说明

[English](../en/release/v12.5.2.md)

v12.5.2 发布于 2026-05-14。本版本修复 OpenCode bash 自动批准配置：不再写入 OpenCode schema 不支持的 `bypass`，改由 Hypo-Workflow plugin policy 在合法 `ask` 配置下批准安全本地命令。

## Fixes

- OpenCode `opencode.json` 现在显式保持 `*: ask`、`edit: ask`、`bash: ask`、`question: allow`。
- 新增 `execution.bash.mode=allow_local`，由 Hypo-Workflow policy 自动允许本地 test/lint/build/format/sync/docs repair 和本地检索命令。
- `git push`、PR/MR remote write、网络命令、remote clone、publish、破坏性命令、系统安装和 release publish 继续 Ask。
- 新增 `opencode-bash-auto-policy` 结构化规则，防止未来重新生成 `permission: bypass`。

## Tests

- OpenCode bash policy、config/profile、adapter artifacts 和 generated plugin 测试通过。
- `opencode debug config` 通过，确认 OpenCode schema 不再报错。
