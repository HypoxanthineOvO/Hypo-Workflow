# v13.1.0-beta.1 发布说明

[English](../en/release/v13.1.0-beta.1.md)

v13.1.0-beta.1 发布于 2026-05-31。这是 13.1 系列的 beta 版本，基于 v13.1.0-alpha.1 的 Audit / Quality / Optimize 指令体系，补齐本轮 `/hw:quality` 审查发现的日志 schema、Quality 日志集成和通知载荷维护性问题。版本标记为 beta，仍不执行 npm publish。

## 重点

- **Quality 审查闭环**：新增 `.pipeline/quality/quality-001.md`、`actions.yaml` 和 `state.yaml`，记录当前项目质量评分、质量门结论和后续 action queue。
- **C18 Beta 收口**：本版本继承 v13.1.0-alpha.1 的 integration sync / Codex-VSP / VSP-Open-Code 适配背景，重点补齐源仓库 Quality 与日志运行时边界。
- **日志 schema 收口**：lifecycle log 现在支持 `quality` family，并接受 release 准备/部分发布状态 `prepared` 与 `partially_published`。
- **Release family 修复**：修复 `release` 因包含 `lease` 子串而被错误归类为 `recovery` 的问题。
- **通知载荷维护性修复**：`notificationStdinPayload` 不再使用 `new String()` 包装对象，改为显式 plain object，同时保留 `includes()`、`String(stdin)` 和 `toJSON()` 行为。

## 修复

- 修复 `.pipeline/log.yaml` 中 v13.1.0-alpha.1 release 记录无法通过 `validateLifecycleLog` 的问题。
- 修复 `/hw:quality` 规范要求写 `type: quality` 但 runtime log family 未定义的集成缺口。
- 为 release/quality 日志记录补充回归测试，防止后续 release 事件再次被错误分类。
- 为 Hypo-Claw 通知 stdin 载荷补充测试，确认不再返回 `String` 包装对象且仍能序列化原始消息。
