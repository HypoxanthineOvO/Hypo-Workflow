# v14.0.0-alpha.1 发布说明

[English](../en/release/v14.0.0-alpha.1.md)

v14.0.0-alpha.1 是 manifest-based Hypo-Workflow 新架构的第一个 14.0 预发布版本。它取代 `v13.1.0-beta.3`：后者的代码与验证有效，但版本号低估了 Runtime、Host Contract、命令表面和宿主权威边界的破坏性变化。

## 为什么是 Alpha

- 核心路径已经可用并通过完整验证，但 Runtime Schema、安装协议和平台适配仍可能调整。
- Codex 是当前主路径；OpenCode、Claude Code、实验项目管理和 Stash/Pop 仍有后续工作。
- 在真实项目验证和公共契约冻结之前，不承诺 14.0 Beta 稳定性。

## 修复与版本纠正

- 纠正 `v13.1.0-beta.3` 对架构变化规模和稳定阶段的错误表达，不移动或删除历史 Tag。

## 核心变化

- Hypo-Workflow 独占生命周期、Runtime、Records、Receipts、Recovery Journal 和 workspace 写入权威。
- 公共命令固定为 `guide`、`init`、`goal`、`plan`、`cycle`、`maintain`、`resume`、`accept`、`reject`。
- Host Contract v1 提供严格递归校验的只读 Host Status；损坏、失效、旧格式和敏感字段均 fail closed。
- Codex plugin ZIP 与 portable ZIP 绑定源码 commit 和 SHA-256，并使用可复现构建。
- 删除操作绑定精确 manifest、一次性 Receipt 和执行报告。

## 验证

- Hypo maintained Core `486/486`、scenarios `8/8`、Bootstrap `67/67`。
- Codex Host/routing/TUI/palette `5/5 + 4/4 + 8/8 + 1/1`。
- OpenCode Host/真实 ZIP `7/7`、相关 broad `26/26`。
- 真实 portable ZIP 已通过完整临时 active-root 安装链。

## 后续阶段

计划在公共契约基本冻结、Codex 真实项目运行稳定并完成 OpenCode 主要适配后进入 `v14.0.0-beta.1`。
