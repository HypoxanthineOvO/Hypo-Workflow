# v12.8.1 发布说明

[English](../en/release/v12.8.1.md)

v12.8.1 发布于 2026-05-17。本版本合入 PR #8，重点是 Cursor adapter 的 flat Skills/commands 同步和 `/hw-setup` 自包含修复。

## 重点

- **Cursor flat Skills/commands**：`hypo-workflow sync --platform cursor --project .` 现在会为每个 `/hw-*` 入口生成 `.cursor/skills/hw-*.md` 和 `.cursor/commands/hw-*.md`。
- **Compact resource bundle**：新增 `.cursor/hypo-workflow/`，镜像 Cursor 执行所需的 compact shared references、assets、adapters 和 scripts。
- **模型边界保持清晰**：Cursor adapter 明确不写入或推荐具体模型/provider 默认值，模型选择仍由 Cursor UI/session 负责。
- **PR #8 归档**：本次合入保留了本地 `.pipeline/pr/PR-20260517-001/` 审阅证据，记录 request changes、修复、approve 和 merge 过程。

## 修复

- 修复 Cursor `/hw-setup` 生成内容曾指向未镜像 `references/config-spec.md` 的问题。
- `/hw-setup` 现在声明为 self-contained；如果遇到 source-repository 路径但目标项目中不存在，按 external/non-local 处理，并使用嵌入 authority 与 mirrored resources 作为 fallback。
- 新增 generated Cursor Skill reference 回归检查，防止生成 Skill 引用不可解析且没有 fallback 的本地路径。
- lifecycle log validator 和 `references/log-spec.md` 新增 `pr` family 与 PR review/merge 状态，确保 `.pipeline/pr/` 归档事件能通过完整回归验证。

## 文档与同步

- README / README.en 指向 v12.8.1 release notes。
- Cursor Guide、Platforms Reference、Generated Artifacts Reference 和 Skill spec 更新为 flat Skills/commands 结构。
- 版本源同步到 12.8.1：`.claude-plugin/plugin.json`、`.codex-plugin/plugin.json`、`.opencode/package.json`、`cli/package.json`、`core/package.json`、默认配置版本和 generator `HW_VERSION`。
