# v12.7.0 发布说明

[English](../en/release/v12.7.0.md)

v12.7.0 发布于 2026-05-14。本版本新增 OpenCode 命令注册和 TUI 面板增强。

## 主要变更

### OpenCode 命令注册

- 在 `opencode.json` 中添加 `command` 字段，注册所有 `/hw-*` 命令
- 修复 `/hw-start`、`/hw-resume` 等命令的参数错误
- 命令模板自动加载对应的 Hypo-Workflow skill 文件
- 已分发到所有本地仓库（26 个）

### TUI 面板增强

- 添加防抖刷新（150ms debounce），避免频繁重渲染
- 添加 Cycle 切换加载动画
- 添加智能折叠：超过 4 项或 200 字符的区块自动折叠
- 添加 ASCII 进度条 `[████░░] 80%`
- 添加区块标题颜色编码（Current=青色, Models=品红, Milestones=绿色, Metrics=蓝色, Recent=黄色, Warnings=红色）
- 添加状态关键字着色（active=绿色, done=灰色, error=红色, pending=黄色, paused=蓝色）
- 添加 ID 着色（C13, M0, F001 等为青色）
- 添加点击区块标题折叠/展开交互

### 权限配置

- `opencode.json` 权限全部设为 `allow`
- bash 执行审批全部关闭（`confirm_external/destructive/system_install: false`）
