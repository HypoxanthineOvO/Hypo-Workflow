# v12.8.0 发布说明

[English](../en/release/v12.8.0.md)

v12.8.0 发布于 2026-05-16。本版本收束 C15 Workflow 交互细节改进，并完成发布前回归修复。

## 重点

- **P2 技术路线门控**：P2 不再只交付 Milestone 目标列表。进入 P3 前必须展示每个 Milestone 的技术方案、技术路线、调研依据、风险、不确定性和审核问题。
- **完成汇报契约**：Milestone、Cycle、Debug、Audit 和 Patch 的完成汇报必须覆盖改动内容、技术思路、修改文件/模块、测试设计、验证结果、预期结果、遇到的问题和风险/后续。
- **Analysis 恢复**：`/hw:analysis` 重新成为一等入口，拥有独立 Skill、命令映射、状态展示、ledger 路径和 compact summary。
- **Shared asset path contract**：修复 `cycle` 子技能误把共享 `assets/state-init.yaml` 当作子技能本地路径的问题，并增加防回归检查。

## 修复

- 发布前完整回归从 55/68 修复到 68/68。
- 更新 v8/v9 scenario smoke，使断言支持当前中文/双语技能文案、Guide/Showcase/PROGRESS 契约和固定字符串匹配。
- 更新 core contract tests，使其匹配当前 OpenCode `allow` 策略、DeepSeek model matrix、rich TUI plugin surface、Subagent separation 中文契约和 workflow commit 中文文案。
- lifecycle log validator 新增 `completed_with_transport_error`，匹配真实 worker transport-error 完成记录。
- OpenCode panel 测试补齐 fake `solid-js` 的 `For` export。

## 文档与同步

- README / README.en 指向 v12.8.0 release notes。
- 版本源同步到 12.8.0：`.claude-plugin/plugin.json`、`.codex-plugin/plugin.json`、`.opencode/package.json`、`cli/package.json`、`core/package.json`、默认配置版本和 generator `HW_VERSION`。
- 刷新 OpenCode adapter 和派生 compact/health 视图，保持发布包元数据一致。
