# v12.7.0 发布说明

[English](../en/release/v12.7.0.md)

v12.7.0 发布于 2026-05-15。本版本完成 C14 全面兼容性审查与修复。

## 审查成果

- **5 个审查域**：Workflow 语义、跨平台适配器、Prompt/规则冗余、测试健壮性、文档引导
- **24 项正式发现**：P0=6（文档缺口）、P1=11（评分矛盾/版本漂移/重叠/规则缺失）、P2=14
- **10 份审查报告** + `findings.yaml` + `fix-queue.md` + `compatibility-checklist.md`

## 修复

### 状态评分
- 统一 `code_quality` 评分量表方向（V1 "越高越好" → V4 "1=好/5=差"）
- 明确 V4 STOP 规则在 `adaptive_threshold=false` 时的兼容性行为

### 平台同步
- 生成器 `HW_VERSION` 常量更新到 12.7.0，全局源同步
- 创建 `.opencode/hypo-workflow.json.analysis` analysis sidecar
- 修复 `opencode.json` 命令注册在 sync 后被清除的问题（`injectCommands` 函数）
- 彩色 TUI 面板持久化到模板，sync 不再覆盖

### 规则与清理
- 移除退役 dashboard Skill
- 创建 `rules/builtin/claude-hw-command-namespace.yaml` 规则文件

### Prompt 优化
- SKILL.md 角色分层：索引 + 路由，指向独立 Skill 文件
- 输出语言规则集中化 `@include: output-language-rule`
- 同步 SKILL.md 与 commands-spec.md 命令列表

### 测试
- i18n 正则双语化，修复 23 个英文正则匹配中文文本的失败测试
- `readme-update.test.js` 命令计数动态化（5 文件/31 测试全部通过）

## 文档

- 创建 CONTRIBUTING.md（159 行）
- developer.md 从 10 行扩展到 211 行（zh/en）
- configuration.md 英文版从 64 行同步到 261 行
