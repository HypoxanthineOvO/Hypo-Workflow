# v12.3.0 发布说明

[English](../en/release/v12.3.0.md)

v12.3.0 发布于 2026-05-09，重点是把 GitHub PR #5 的 worker-separation 功能干净集成到当前主线，并补齐运行结束后的 compact 刷新与 OpenCode status 边界。

## Features

- 新增 worker-separation acceptance hardening：`/hw:accept` 现在会检查 `test` / `implement` / `audit` worker evidence、身份碰撞、Codex 授权范围、role availability 和 worker lifecycle。
- 新增运行结束后的 dirty-only compact refresh：`/hw:start` 和 `/hw:resume` 成功完成后，在 `compact.auto=true` 且 `compact.end_of_run=true` 时只刷新变脏的 compact targets。
- 更新 OpenCode status/runtime 展示：active subagent/model 可展示为 runtime-only 信息，但不能满足 `/hw:accept` 的持久 worker evidence。

## Fixes

- 干净集成 GitHub PR #5：保留 `feat: harden worker separation acceptance` 的功能内容，丢弃旧 PR #3 的 `13.0.0` 版本 bump 和过期 `.pipeline/` 运行态。
- 修复新增 worker-separation 回归测试对外部 `rg -g` 行为的依赖，改为纯 Node 文件扫描，保证场景回归里的 `tests/bin/rg` 环境稳定。
- 收紧 Cycle acceptance 的 follow-up continuation 清理逻辑，避免非 follow-up 接受路径残留旧 continuation。
