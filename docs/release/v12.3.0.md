# v12.3.0 发布说明

[English](../en/release/v12.3.0.md)

v12.3.0 发布于 2026-05-09，重点是把 GitHub PR #5 的 worker-separation 功能干净集成到当前主线，并补齐运行结束后的 compact 刷新与 OpenCode status 边界。

## 关键变化

- `/hw:accept` 现在会阻塞缺失或身份碰撞的 `test` / `implement` / `audit` worker evidence、失败或 `close_failed` lifecycle、缺少 Codex `/hw:start` + `/hw:resume` 授权范围，以及 runtime-only subtask observation 被误当作验收 evidence 的情况。
- `/hw:start` 和 `/hw:resume` 成功完成后，会在 `compact.auto=true` 且 `compact.end_of_run=true` 时按默认 `compact.refresh_policy=dirty_only` 只刷新变脏的 compact targets。
- OpenCode status 可以展示 active subagent/model，但这些 `subtask` parts 必须标记为 runtime-only，不能满足 `/hw:accept` worker evidence。
- GitHub PR #5 被本地干净集成：保留 `feat: harden worker separation acceptance` 的功能内容，丢弃旧 PR #3 的 `13.0.0` 版本 bump 和过期 `.pipeline/` 运行态。
