# v13.1.0-beta.2 发布说明

[English](../en/release/v13.1.0-beta.2.md)

v13.1.0-beta.2 源仓发布候选准备于 2026-06-30。这是 13.1 系列的 beta 版本，合并 C19 Workflow 核心内容与 Plan 模式优化，以及 C20 协商优先的修改启动风格。版本仍保持 beta，不执行 npm publish；C20 对 `Codex-VSP` 和 `VSP-Open-Code` 只交付 target-local Cycle handoff，不声明目标仓已经部署。

## 重点

- **命名 Plan 阶段**：Plan 用户面收敛为 `Discover -> Technical Stack -> Architecture -> Decompose -> Generate`，新增 `/hw:plan:technical-stack` 与 `/hw:plan:architecture`。
- **阶段内可见 Gate**：重大确认前必须先展示阶段摘要、决策表、开放问题和图表，再使用 Question Tool / Ask；`/hw:plan:confirm` 不再作为用户态入口。
- **协商优先修改边界**：讨论、背景、想法、抱怨、问题和方案讨论是 non-editing signals，必须先输出 Mini-contract，顺序为 `我的理解` -> `问题原因` -> `推荐方案`。
- **Direct execution 保留**：明确祈使且有具体目标的任务仍可直接执行；计划后 `可以`、`确认`、`OK`、`go ahead`、`apply it` 只授权已展示范围。
- **目标仓 handoff**：新增 `Codex-VSP` 与 `VSP-Open-Code` 的 C20 target-local Cycle 输入包，明确 source direct sync 和 target-owned prompt/runtime 优化边界。

## 功能

- 新增 C19 Plan 命令合同和阶段拆分，覆盖 Technical Stack、Architecture、Decompose、Generate 的职责边界。
- 新增 phase flow、milestone table、decision matrix、dependency map 等阶段产物 renderer，用于确认前展示可审查材料。
- 新增 C20 source-side 行为合同 `references/consultation-first-action-boundary.md` 和场景测试。
- 将 C20 共享指导投影到 OpenCode command/agent/root surfaces、Claude command/agent surfaces、根 `AGENTS.md` 和生成命令说明。
- 新增 `.pipeline/integrations/C20-target-cycle-input.md`，为 `Codex-VSP` 与 `VSP-Open-Code` 后续目标仓本地 Cycle 提供候选文件、验证命令和 acceptance target。

## 修复

- 修复当前用户面文档和命令描述中旧 P1/P2/P3/P4 阶段残留；legacy/internal alias 仍按兼容说明保留。
- 修复 lifecycle log 对 visible gate feedback family 和状态的校验缺口，允许真实 gate 记录通过回归。
- 修复 managed instruction surfaces stale 问题，使生成后的 OpenCode、Claude、命令和根指令表面都包含协商优先边界。
- 修复 C20 handoff 前 `.pipeline/integrations/matrix.yaml` 仍停留在 C19 状态的问题。
