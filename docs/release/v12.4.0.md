# v12.4.0 发布说明

[English](../en/release/v12.4.0.md)

v12.4.0 发布于 2026-05-11，重点是 C11 工作流体验收口：中文优先的 Skills / references、Plan 访谈与示例抽象、Subagent 注入纪律、自动化授权白名单，以及本地分发前的完整回归修复。

## 关键变化

- Skills 和关键 references 改为中文主体结构，同时保留命令名、配置键、文件名和平台术语的英文原文。
- `/hw:plan` 相关流程强化 P0/P1 访谈，要求先抽象用户给出的例子，再进入 milestone 分解。
- Subagent 模板补齐 Layer 1 host envelope 与 Layer 2 task checks，避免把宿主规则和任务检查混在一起。
- 自动化授权白名单、Codex Subagent 授权范围、worker separation 和 analysis 边界被写入配置、报告和验证链。
- 场景回归 `s19-help-list` 与 `s56-agents-ask-todo-plan-discipline` 已更新为中文化后的权威锚点，避免继续依赖旧英文标题。
