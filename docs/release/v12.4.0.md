# v12.4.0 发布说明

[English](../en/release/v12.4.0.md)

v12.4.0 发布于 2026-05-11，重点是给验收命令新增更符合完成语义的别名，同时刷新三端适配器。

## 变更

- 新增 `/hw:achieve`，作为 `/hw:accept` 的 alias。
- OpenCode 新增 `/hw-achieve` native command，仍路由到 `skills/accept/SKILL.md`。
- `/hw:achieve` 与 `/hw:accept` 共用同一套 worker-separation gate、Cycle acceptance lifecycle、log entry 和 derived refresh 规则，不创建第二条验收路径。
- 版本元数据更新为 `12.4.0`，README、用户指南、命令参考和 Skill inventory 同步到 40 个用户指令。

## 验证

- 针对性测试覆盖 command map、accept/achieve 映射、Skill inventory、docs governance、README 更新和平台适配器。
- 三端适配器通过 `hypo-workflow sync --platform opencode` 与 `hypo-workflow sync --platform claude-code` 重新生成。
