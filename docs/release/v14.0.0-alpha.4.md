# v14.0.0-alpha.4 发布说明

[English](../en/release/v14.0.0-alpha.4.md)

v14.0.0-alpha.4 允许同一个 Project 安全地并行维护多个 Delivery 与 Experiment，同时确保一个 Session 只处理一个明确选择的 Work Item。本版本继承 v14.0.0-alpha.3 的 Codex Hook 并发修复，并把并发控制扩展到 repository、worktree、GPU、port、cache 与 output 等实际执行边界。

## 功能

- 新增 **Repository Target registry**：稳定 repository identity 与可变 locator 分离；一个 permanent primary integration target 始终存在，并允许登记备用 integration target。
- 新增 **Work Placement registry**：Goal、Plan、兼容 Cycle 映射为 Delivery Work Item，Experiment 保持独立 Work Item；同一 Project 可以同时拥有多个 active Work Item。
- 每个 **Session** 必须显式绑定一个 Work Item。存在多个候选时返回 `selection_required`，不会静默继承 legacy `active.delivery`，也不会把两个任务混在同一上下文。
- Placement preflight 原子评估 repository access、build、GPU、port、cache、filesystem 与 output claim，结果为 `shared`、`isolated_worktree`、`isolated_resources` 或 `blocked`。
- 不同 source snapshot 或源码变更返回 bounded `git worktree` Host descriptor；可重定位资源获得确定的隔离 locator。Core 不直接运行 Git、进程或 GPU 命令。
- lease、renew 与 **fencing** 防止两个进程同时取得独占资源；过期 owner 在资源被新 owner 接管后不能复活、释放对方资源或记录 integration。
- 源码变更必须提供 **integration** evidence。证据绑定 Repository Target 中登记的 checkout、branch ref、source/result commit、target HEAD 与 ancestry，并在最终验收门重新校验；不存在 abandon 绕行路径。

## 修复

- expired-only Placement registry 返回可管理的空候选状态，不再让 UserPrompt、PreToolUse 或 PermissionRequest 永久死锁。
- selected Experiment 在 PreCompact/PostCompact 没有 Delivery Recovery Capsule 时安全继续。
- Host status 投影 available Work Items、Session selection 和 expired lease，同时保持没有 Placement registry 的旧 workspace 可用。
- 合并 v14.0.0-alpha.3 时保留原子 reminder marker，并将“等价 Host projection 已被并发新事务覆盖”的安全收尾语义移植到新的 writer lease/fencing 内核。

## 验证

- failure-first Placement contract 从 `1 fail / 8 skip` 开始，最终 Repository、Placement、Session、fresh-process fencing、integration 与 legacy 契约全部通过。
- Placement、Host、Hook 与 workspace transaction 交叉回归：`59/59 PASS`。
- maintained full suite：`710/710 PASS`。
- 独立实现审计：`PASS`，`0 blocking findings`。
- Host plugin 与 portable bundle 在干净 source commit 上构建，并通过 manifest、SHA-256 与临时安装验证后发布。

## 已知边界

- Core 只验证并返回结构化 Host descriptor；真实 worktree 创建、GPU/port 分配、实验进程和 Git integration 仍由 Host 执行。
- Cryo-Computing 的 Accel-Sim/Trace 拓扑通过 filesystem fixture 验证；本版本发布本身不启动真实实验。
- Placement 历史条目继续保留，后续可以增加显式 retention/compaction，而不改变 active lease 与 fencing 语义。
