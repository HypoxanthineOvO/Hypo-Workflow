# v14.0.0-alpha.6 发布说明

[English](../en/release/v14.0.0-alpha.6.md)

v14.0.0-alpha.6 解除 Experiment 记录与 Hook 辅助能力之间的不必要耦合，并修复 CLI Root Core export 缺失。核心原则是：Hooks 负责提醒和守护，普通文件负责可读记录，辅助能力不可用时宿主 Agent 仍能继续完成工作。

## Experiment 记录

- 默认 protocol 使用一个可读的 `experiment.yaml` 和每次 Attempt 的独立 YAML 文件；格式与字段定义见 `docs/reference/experiment-records.md`。
- 命名报告工具、BatchReport 类宿主能力、content-addressed events、哈希校验和物化 status projection 均为可选辅助或兼容能力。
- 辅助工具不可用时，Agent 直接更新普通 YAML；不得因此停止实验命令、长任务监督、结果分析或记录写入。

## Hook 行为

- Session 未绑定 Work Item 时，`SessionStart` 与 `UserPromptSubmit` 提供可见上下文和候选项，但不再封锁普通 prompt 或全部工具。
- Work Placement 仍用于 Workflow authority 写入和 GPU、端口、cache、输出目录等资源 claim；它不再成为宿主工作的全局前置条件。
- Hooks 不再通过关键词抽取用户语义并自动写入 inbox。主 Agent 负责判断明确的长期 requirement、preference、decision 和 feedback，再通过 Maintain 持久化。
- 辅助 Hook 处理异常时返回 warning 并允许宿主继续；显式删除和受控破坏性操作的 guardrail 保持严格。

## CLI 与 Planning 修复

- Root Core 重新导出 sync、TUI、maintenance、project-event 和 notification API，修复 `buildGlobalTuiModel` 缺失导致 `hypo-workflow sync --check-only` 启动失败的问题。
- 写入型 sync 仍保持退役；`--check-only` 只检查 derived artifacts，不修改目标 workspace。
- Goal / Plan Discussion 一次展示 Discover、Technical 与 Architecture artifact，只在真实决策和最终 Proposal 处询问；固定轮数和逐阶段仪式化确认已移除。

## 验证

- Maintained Core suite 覆盖 Hook、Experiment protocol、planning 与 root-export 回归。
- Codex Hook smoke 覆盖真实 wrapper 输入输出和 fail-open / guardrail 边界。
- 发布构建校验插件结构、ZIP 内容、锁文件依赖、manifest checksum 与干净解压后的运行时加载。

## 升级说明

- 新版本只对新 Session 生效；仍引用旧 `PLUGIN_ROOT` 的 Session 应继续使用其固定 cache，直到自然结束。
- Experiment 的 legacy events / projection 可继续读取，但新记录应优先使用普通 YAML protocol。
