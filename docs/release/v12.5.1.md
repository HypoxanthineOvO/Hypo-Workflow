# v12.5.1 发布说明

[English](../en/release/v12.5.1.md)

v12.5.1 发布于 2026-05-12。本版本修复 Claude Code `hw` plugin 的 slash command 暴露方式，并把 release notes 调整为规范分类结构。

## Features

- Claude Code plugin 现在生成 plugin-root `commands/*.md` slash command files，让 `/hw:*` 在 Claude Code 中恢复补全和入口发现。
- 新增 40 个 Claude Code command mappings，包括 `/hw:patch`、`/hw:resume`、`/hw:plan:deep`、`/hw:plan:discover` 等常用入口；命令文件只加载现有 `skills/*/SKILL.md` authority，不引入第二套实现。
- 新增 `/hw:plan:deep` 深度讨论/计划入口，用 discussion package 承载 ask、research、architecture map、readiness 和 Feature Queue handoff。
- 新增 project structured rule `claude-hw-command-namespace`，以 `error` 级别强制检查 Claude Code 必须使用 `hw` namespace 暴露 `/hw:*`，并保持 Claude 原生 `/resume` 与 Hypo `/hw:resume` 分离。

## Fixes

- 修复本机 Claude Code 只显示 `/hypo-workflow` 聚合入口、`/hw:` 没有补全的问题。
- 修复旧文档和 setup skill 中把 Claude Code 主入口描述为 `/hypo-workflow:<command>` 的问题。
- 保留 `/hw:resume` 命名空间，不注册裸 `/resume`，避免再次与 Claude Code 原生 Resume 冲突。
- 将 v12.3.0、v12.4.0、v12.5.0 中文 release notes 调整为 `Features` / `Fixes` / `Documentation` / `Tests` 分类结构。

## Documentation

- 更新 Claude Code 平台指南、平台能力矩阵、commands spec 和 setup skill，明确 plugin-root `commands/` + `hw` namespace 的实现边界。
- GitHub Release 文案已按规范改为中文分类版；`docs/en/**` 继续保持英文正文。
