# v13.0.0-alpha.1 发布说明

[English](../en/release/v13.0.0-alpha.1.md)

v13.0.0-alpha.1 发布于 2026-05-20。这是 C16 根目录项目管理模式的预发布版本，用于交付全局维护、Notion legacy reconciliation、Knowledge projection 和维护调度能力；该版本标记为 alpha，不声明稳定发布。

## 重点

- **根目录项目管理模式**：新增 Global Workspace authority、Artifact Catalog、Storage Sync Template、Maintenance Queue/Ledger/Run、Global Consolidation、Global Knowledge/Rules/Secret Reference projection 和最终 Notion apply gate。
- **一等维护命令面**：新增 `/hw:maintain status|scan|plan|queue|run|apply|verify|log`，让长期维护对象、分块维护、系统自发维护和用户手动维护不再隐藏在 `/hw:sync` 或普通 Cycle 中。
- **每日 04:00 全局沉淀**：新增 `hypo-workflow maintain-scheduler --dry-run` 与 `scripts/maintenance-scheduler.sh`，可生成 safe-local global consolidation evidence 和 maintenance ledger event，不执行 Notion apply、发布、服务重启或 pipeline execution。
- **项目级全局知识读取**：新增项目级 Global Knowledge projection 与 compact renderer；SessionStart 只读加载 `~/.hypo-workflow/knowledge/projections/projects/<project-id>.compact.md` 和 YAML index，不默认读取 raw global records/candidates。

## 修复

- 修订 C16 验收反馈后的 Notion 同步方向：从创建额外同步子页改为整理现有 `Hypo-Workflow` 主页和既有子页面，使用 scan、manifest、merge draft、safe apply payload、备份和读回验证分阶段处理。
- 强化最终 Notion apply gate：要求 dry-run hash、reviewed apply plan id/hash、精确确认短语、显式 target binding、approved operation subset、re-read verification 和 sanitized ledger/evidence。
- 修复 SessionStart hook stdout 契约，确保 hook 只输出可解析 JSON，并把 Global Knowledge compact 作为 additional context 注入。
- Notion legacy reconciliation 修订中清理了错误的 flat index、`归位 —` 标题前缀、quote 残留、伪 Markdown 代码块、`top[n]` 标记和裸 Markdown 标题残留。

## Alpha 边界

- 本版本不执行 release tag、push、publish 或远端 release 创建。
- Notion 页面整理已按用户授权执行并记录备份；后续 destructive cleanup 或新增远端写入仍需要明确确认。
- Global Knowledge projection 只加载 compact/index；raw secret 和 raw session 内容仍留在本地 authority 或 secret store 边界内。
