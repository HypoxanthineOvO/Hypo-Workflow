# RTL M07-M09 Prompt Coverage

## M07 Discover

- Detect RTL intent from HDL, Verilog, SystemVerilog, SpinalHDL, combinational/sequential, clock/reset, testbench, simulator, waveform, FPGA, ASIC, or synthesis terms.
- Ask for target language and design kind when ambiguous.
- For sequential designs, ask about clock/reset behavior early.

## M08 Implement

- Keep design modules synthesizable unless the user explicitly asks for testbench-only code.
- Separate RTL files from testbench files.
- Use HDL-specific review points: complete combinational assignments, nonblocking updates for sequential registers, reset handling, and interface widths.

## M09 Verify

- Prefer simulator evidence over static inspection alone.
- Record command, simulator name/version when known, log outcome, waveform note, or blocker.
- Probes may inspect local metadata only; they must not install tools, fetch remote pack code, or run unconfirmed external code.
